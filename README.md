# MySQLite

Repositório criado para armazenar exercícios práticos de SQL utilizando MySQLite.
Exercicios da curso SQLite online: Conhecendo instruções SQL da plataforma Alura.

- Conteúdos praticados
- Criação de tabelas
- Inserção de registros
- Consultas com SELECT
- Filtros com WHERE
- DISTINCT
- Atualização de registros com UPDATE
- Exclusão de registros com DELETE
- Criação de chaves primárias (PRIMARY KEY)
- Criação de chaves estrangeiras (FOREIGN KEY)
- Relacionamento entre tabelas
- Consultas utilizando JOIN
- Exclusão de tabelas com DROP TABLE
